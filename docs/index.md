## :material-information: How It Works

1. Authors create or edit markdown files in the `docs/` folder
2. A Pull Request is opened for review
3. A preview deployment is generated automatically for verification
4. Once merged, the site is published to GitHub Pages

## :material-star: Features

- **Markdown-based** — Write content in familiar markdown syntax
- **Full-text search** — Find any document instantly with client-side search
- **Auto-navigation** — Site structure mirrors the folder hierarchy
- **Preview deployments** — Review changes before they go live
- **Mermaid diagrams** — Flowcharts and architecture diagrams in code
